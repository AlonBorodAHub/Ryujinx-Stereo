passed for both eyes/order, one presentation per pair, native shared-context
synchronization and graphics-state preservation. The user confirmed corrected
Zelda ground shadows, menu lighting, fog/smoke, stereo and colors, and smooth
native output in both games. Mario launched through the separate dEPTH
frontend was confirmed as smooth as the desktop emulator with correct 3D.

passed: upright eye order/colors, 3840x2160 H.264 at exactly 60/1 fps, audible
AAC, equal audio/video duration, preserved game GL state, and safe repeated
start/stop/immediate cancellation. The save-before-close test returned the
output path only after MP4 finalization. Both engines compiled after adding
foreground-only fullscreen hotkeys. The user confirmed F9/F10 closed Zelda
and showed the saved MP4. That gameplay clip was not independently located
or decoded; codec/audio assertions refer to the separate synthetic GPU test.

Publication source builds passed for both engines. Relocated library startup
loaded the clean portable configuration with OpenGL and FXAA; --help opens
the library in this frontend rather than exiting. No game was loaded.
Release preparation checks runtime hashes and archive exclusions. The download
uses allow-listed runtime files and fresh keyboard configuration, without
private profiles or game data.
